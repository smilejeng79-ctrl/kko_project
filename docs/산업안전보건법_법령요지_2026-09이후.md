## 2. 항목별 법령요지

### 2-1. 위험성평가 근로자 참여 의무화 (법 제36조, 2026.6.1 시행)

| 구분 | 내용 | 위반 시 (과태료 상한) |
|---|---|---|
| 실시 의무 | 위험성평가 실시 | 1,000만 원 이하 |
| 근로자 참여 | 평가 전 과정에 근로자 참여 의무 / 근로자대표 요구 시 참여 | 500만 원 이하 |
| 결과 공유 | 결과를 근로자에게 주지·게시 | 500만 원 이하 |
| 기록·보존 | 결과·조치내용 기록 보존 | 300만 원 이하 |
| 과태료 적용 | 50인 이상: 2027.1.1 / **50인 미만: 2028.1.1** | — |

**현장 행동 포인트**
- 의무는 **이미 발효**. 과태료 유예 기간은 "준비 기간"이지 "면제 기간"이 아니다.
- 증빙 = 참여 노동자 서명·사진·TBM 기록. 별도 서식보다 **회의 사진 + 1장 결과표 게시**가 가장 현실적.

### 2-2. 2026.10.1 국회 통과 개정안 (공포 대기)

| 항목 | 요지 | 시행 |
|---|---|---|
| 사망재해 과징금 | 안전·보건조치 의무 위반으로 **1년간 3명 이상 사망** 시 **영업이익 5% 이내** 과징금 / 영업이익 없거나 산정 곤란 시 **30억 원 이내** / 시행 후 발생 사고부터 적용 / 산재보험기금 귀속 | 공포 후 6개월 |
| 등록말소 요청 | 최근 3년간 영업정지 2회 받은 사업주가 다시 영업정지 대상이 되면 장관이 관계기관에 등록말소 요청 | 공포 후 6개월 |
| 노동자 작업중지권 확대 | 요건 완화: "급박한 위험이 있는 경우" → **"급박한 위험이 있거나 우려되는 경우"** | 공포 후 6개월 |
| 하청 노동자 작업중지 요구 | 소속 사업주뿐 아니라 **원청에도** 작업중지 등 조치 요구 가능 | 공포 후 6개월 |
| 사업주 작업중지 의무·장관 작업중지명령 | 사유·대상 확대 | 공포 후 6개월 |
| 신고포상금 | 법 위반 신고자 포상금 지급 근거 | 공포 후 3개월 |
| 안전한일터위원회 | 정부 위원회 신설 | 공포 후 3개월 |

> 세부 부과기준(규모·위반행위별 산정)은 **시행령 위임** → 하위법령 입법예고를 추적해야 한다.

**50인 미만 영향**
- 과징금 요건(1년 3명 사망)은 소규모에 직접 해당 가능성 낮음. 그러나 **원청 협력업체**로서 원청의 안전관리 요구가 강해진다.
- **작업중지권 행사 절차**(누가·언제·어떻게 멈추고 보고하는지)를 현장 규칙으로 정해두지 않으면 분쟁 위험.
- 신고포상금 도입 → **기본 의무(보호구·안전난간·끼임방호·폭염휴식) 미이행이 외부 신고로 드러날 가능성** 증가.

| 금지물질 수입 | 화학물질관리법상 수입허가 받으면 별도 장관 승인 불요 | — |
