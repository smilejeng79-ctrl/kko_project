# 산업안전보건법 법령요지 (전체)

> 사업장 게시용 · 산업안전보건법 제34조(법령 요지 등의 게시)
> 작성 기준일: 2026-10-13 / 기준: 공포되어 현재 시행 중이거나 시행일이 확정된 법령 (법·시행령·시행규칙·안전보건규칙)
> 세부 기준과 업종별 적용 범위는 국가법령정보센터(law.go.kr) 원문을 확인한다.

---

## 0. 목적과 의무 주체

| 구분 | 요지 | 조문 |
|---|---|---|
| 목적 | 산업 안전·보건 기준을 확립하고 책임 소재를 명확하게 하여 산업재해를 예방하고, 노무를 제공하는 사람의 안전과 보건을 유지·증진 | 제1조 |
| 정부 | 산업 안전·보건 정책 수립·집행, 사업주 자율 예방활동 지원, 기술·교육 지원 | 제4조 |
| 사업주 | 법령상 산업재해 예방기준 준수 / 쾌적한 작업환경 조성과 근로조건 개선 / 사업장 안전·보건 정보 제공 | 제5조 |
| 근로자 | 법령상 산업재해 예방기준 준수 / 사업주·근로감독관·공단 등의 재해예방 조치에 협조 | 제6조 |

## 1. 안전보건관리체계

| 구분 | 선임·설치 대상 | 주요 역할 | 조문 |
|---|---|---|---|
| 안전보건관리책임자 | 업종별 상시 50·100·300명 이상 / 건설 공사금액 20억 원 이상 | 사업장 안전보건 총괄 | 제15조 |
| 관리감독자 | **모든 사업장** (생산 업무 지휘·감독 직위자) | 소관 작업 안전점검, 보호구 착용 지도, 위험성평가 참여 | 제16조 |
| 안전관리자 | 업종별 상시 50명 이상 / 건설 공사금액 50억 원 이상 | 안전 기술 보좌·지도 | 제17조 |
| 보건관리자 | 업종별 상시 50명 이상 | 보건 기술 보좌·지도 | 제18조 |
| 안전보건관리담당자 | 상시 **20~50명 미만**, 5개 업종 (제조업, 임업, 하수·폐수·분뇨 처리업, 폐기물 수집·운반·처리업, 환경 정화·복원업) | 안전보건교육, 위험성평가, 작업환경측정·건강진단 지원 | 제19조 |
| 산업안전보건위원회 | 상시 100명 이상 (일부 업종 50명 이상) / 건설 120억 원 이상 | 노사 동수 구성, 분기 1회 이상 정기회의 | 제24조 |
| 안전보건관리규정 | 상시 100명 이상 (일부 업종 300명 이상) | 작성 후 근로자에게 게시·비치 | 제25조 |
| 명예산업안전감독관 | 위촉 가능 (근로자대표 추천 등) | 사업장 점검·감독 참여, 개선 건의 | 제23조 |

> **50인 미만 핵심**: 관리감독자 지정 + (해당 업종) 안전보건관리담당자 선임 + 위험성평가 + 안전보건교육

## 2. 안전보건교육 (제29조·제31조, 시행규칙 별표4)

| 교육 | 대상 | 시간 |
|---|---|---|
| 정기교육 | 사무직·판매 업무 근로자 | 매 반기 6시간 이상 |
| | 그 밖의 근로자 | 매 반기 12시간 이상 |
| | 관리감독자 | 연 16시간 이상 |

| | 근로계약 1주일 초과 1개월 이하 기간제 | 4시간 이상 |
| | 그 밖의 근로자 | 8시간 이상 |
| 작업내용 변경 시 | 일용근로자, 1주일 이하 기간제 | 1시간 이상 |
| | 그 밖의 근로자 | 2시간 이상 |
| 특별교육 (유해·위험 작업) | 일용근로자, 1주일 이하 기간제 | 2시간 이상 |

| 건설업 기초안전보건교육 | 건설 일용근로자 | 4시간 (업무 배치 전, 공단 등록기관) |
| 외국인근로자 기초안전보건교육 | 외국인근로자 채용 시 | **2027.1.8 시행** (제31조의2) |

## 3. 위험성평가 (제36조)

| 구분 | 요지 |
|---|---|
| 실시 | 유해·위험요인을 찾아 위험성을 결정하고 감소대책을 수립·실행 |
| 근로자 참여 | **2026.6.1부터** 평가 과정에 근로자 참여 의무 / 근로자대표 요구 시 참여 |
| 결과 공유 | 결과를 근로자에게 알리고 게시 |
| 기록·보존 | 결과와 조치 내용 기록·보존 (3년) |
| 과태료 적용 | 50인 이상 2027.1.1 / **50인 미만 2028.1.1** |

## 4. 안전조치·보건조치 (제38조~제41조, 안전보건규칙)

| 구분 | 요지 |
|---|---|
| 안전조치 (제38조) | 기계·기구·설비, 폭발·발화·인화성 물질, 전기·열 에너지, 굴착·채석·하역·벌목, 추락·붕괴 위험 장소 등에 대한 위험 방지 |
| 보건조치 (제39조) | 유해물질·분진·소음·진동·고온(폭염)·저온·방사선, 단순반복작업·과중한 신체 부담, 환기·채광·조명 등 건강장해 예방 |
| 폭염 (안전보건규칙) | 체감온도 31℃ 이상: 냉방·통풍, 작업시간 조정, 주기적 휴식 / **33℃ 이상: 2시간마다 20분 이상 휴식** |
| 근로자 준수 (제40조) | 근로자는 사업주의 안전·보건조치 사항을 지켜야 함 (보호구 착용 등) |
| 고객응대근로자 (제41조) | 폭언·폭행 등에 따른 건강장해 예방, 업무 일시 중단·전환 등 조치 / 요구를 이유로 한 불리한 처우 금지 |
| 안전보건표지 (제37조) | 유해·위험 시설·장소에 경고·지시·안내 표지 설치·부착 (외국인 고용 시 외국어 표지) |

## 5. 작업중지와 중대재해

| 구분 | 요지 | 조문 |
|---|---|---|
| 사업주 작업중지 | 산업재해 발생의 급박한 위험 시 즉시 작업 중지, 근로자 대피 | 제51조 |
| **근로자 작업중지권** | 급박한 위험이 있으면 작업을 중지하고 대피 가능 → 지체 없이 상급자에게 보고 / 합리적 근거가 있으면 **불리한 처우 금지** | 제52조 |
| 중대재해 발생 시 | 즉시 작업 중지, 근로자 대피 → **지체 없이 관할 지방고용노동관서에 보고** | 제54조 |
| 중대재해 정의 | ① 사망자 1명 이상 ② 3개월 이상 요양 부상자 동시 2명 이상 ③ 부상자 또는 직업성 질병자 동시 10명 이상 | 제2조 |
| 고용노동부 작업중지명령 | 중대재해 발생 시 해당 작업 또는 전부 작업중지 명령 가능 | 제55조 |

## 6. 산업재해 보고·기록 (제57조)

| 구분 | 요지 |
|---|---|
| 은폐 금지 | 산업재해 발생 사실을 은폐하거나 은폐를 교사·공모 금지 |
| 보고 | 사망 또는 **3일 이상 휴업** 재해 → 발생일부터 **1개월 이내** 산업재해조사표 제출 |
| 기록·보존 | 발생 원인 등 기록 **3년** 보존 |

## 7. 도급 시 산업재해 예방 (제58조~제66조)

| 구분 | 요지 |
|---|---|
| 유해작업 도급 금지 (제58조) | 도금작업, 수은·납·카드뮴 제련·주입·가공·가열 작업 등 사내 도급 금지 (승인 시 예외) |
| 도급인의 안전·보건조치 (제63조) | 도급인 사업장에서 작업하는 관계수급인 근로자에 대해 도급인이 안전·보건조치 |
| 도급인 이행사항 (제64조) | 안전보건협의체 구성·운영, 작업장 순회점검, 교육 지원·확인, 경보체계 운영, 위생시설 설치 장소 제공 등 |
| 안전보건정보 제공 (제65조) | 화학설비 개조·청소, 질식·붕괴 위험 작업 도급 시 안전보건정보를 수급인에게 문서로 제공 |

## 8. 유해·위험 기계와 화학물질

| 구분 | 요지 | 조문 |
|---|---|---|
| 방호조치 | 방호조치 없이 유해·위험 기계를 양도·대여·설치·사용 금지 | 제80조 |
| 안전인증 / 자율안전확인 | 프레스·크레인·리프트·압력용기 등 안전인증, 그 밖의 대상은 자율안전확인 신고 | 제84조·제89조 |
| 안전검사 | 크레인·리프트·압력용기·컨베이어·산업용 로봇·국소배기장치 등 주기적 안전검사 | 제93조 |
| 물질안전보건자료(MSDS) | 제조·수입자 작성·제출 / 사업주는 취급 장소에 **게시·비치**하고 근로자 교육 | 제110조·제114조 |
| 경고표시 | 대상 화학물질 용기·포장에 경고표시 부착 | 제115조 |

## 9. 근로자 보건관리

| 구분 | 요지 | 조문 |
|---|---|---|
| 작업환경측정 | 유해인자 노출 작업장 **6개월마다 1회 이상** 측정, 결과 근로자에게 알림 | 제125조 |
| 건강진단 | 일반: 사무직 2년 1회, 그 외 1년 1회 / 특수·배치전·수시·임시 건강진단 / 결과에 따른 사후조치 | 제129조~제132조 |
| 휴게시설 | 상시 20명 이상(건설 20억 원 이상) 또는 취약직종 2명 이상 고용 10명 이상 사업장 설치·관리기준 준수 | 제128조의2 |
| 유해·위험작업 근로시간 | 잠함·잠수 작업 1일 6시간, 1주 34시간 초과 금지 | 제139조 |

## 10. 근로자의 권리

| 권리 | 요지 |
|---|---|
| 작업중지·대피 | 급박한 위험 시 작업을 멈추고 대피할 권리 (제52조) |
| 참여 | 위험성평가 참여, 산업안전보건위원회 심의·의결, 명예산업안전감독관 활동 |
| 알 권리 | 위험성평가 결과, MSDS, 작업환경측정 결과, 건강진단 결과 설명 요구 |
| 신고 | 법 위반 사실을 고용노동부·근로감독관에게 신고 가능 / **신고를 이유로 한 불리한 처우 금지** (제157조) |
