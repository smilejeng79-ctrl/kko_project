# 지원사업장 안전보건관리 담당자 근골격계 유해요인조사 실무교육 참여 계획(안)

> 콜키퍼 역량강화 교육 연계 · ○○비정규직노동자지원센터 · 2026. 10.

## 1. 사업 개요

| 구분 | 내용 |
|---|---|
| 사업명 | 지원사업장 안전보건관리 담당자 근골격계 유해요인조사 실무교육 |
| 일시 | 2026. 10. 25.(일) 10:00~14:00 (4시간) |
| 장소 | ○○○ (콜키퍼 사업 교육장) |
| 주관 / 협력 | 콜키퍼 사업단(교육 운영) / 센터(대상 모집·사후 연계) |
| 대상 | 센터 지원사업장 안전보건관리 담당자(사업주·관리자 포함) ○○명 + 콜키퍼 ○○명 |
| 예산 | 센터 추가 예산 없음 (강사·교육장은 콜키퍼 사업이 부담) |

## 2. 추진 배경 및 목적

| 배경 | 목적 |
|---|---|
| 근골격계부담작업이 있으면 **3년마다 유해요인조사가 의무**이나(안전보건규칙 제657조), 소규모 사업장은 방법을 몰라 미실시하거나 서류만 갖춰 둠 | 담당자가 **자기 사업장 유해요인조사를 직접 할 수 있게** 만든다 |
| 중대재해처벌법상 유해·위험요인 확인·개선 절차가 50인 미만 사업장에도 적용됨 | 조사 결과가 **개선 실행까지 이어지는 구조**를 몸에 익힌다 |
| 콜키퍼 사업이 교육을 개방해 **센터 예산 없이 전문교육 기회** 확보 | 콜키퍼–지원사업장 담당자 간 **현장 네트워크** 형성 |

## 3. 교육 내용 (안, 콜키퍼 사업 운영안 기준으로 조정)

| 시간 | 내용 | 방식 |
|---|---|---|
| 10:00~10:10 | 등록, 사업장별 대표 작업 1개 적어오기 확인 | 안내 |
| 10:10~11:00 | 법적 의무와 점검 포인트: 조사 주기·시기, 근로자 참여, 통지·사후조치(제657~662조) / 근골격계부담작업 11종 판단법 | 강의 |
| 11:00~11:50 | 조사 방법: 작업장 기본조사표, 근골격계 증상조사표, 부담작업 체크리스트 작성법 | 강의+시연 |
| 11:50~12:20 | 휴식·간편 식사 | — |
| 12:20~13:30 | **참여형 실습**: 사진·영상으로 실제 작업 분석 → 부담작업 해당 여부 판단 → 위험순위 결정 (업종별 조 편성, 콜키퍼 1명씩 배치) | 조별 실습 |
| 13:30~13:50 | **개선 실행카드 작성**: 사업장별 "2주 안에 바꿀 것 1가지" (돈 안 드는 개선 우선) | 개인 작성 |
| 13:50~14:00 | 사후과제 안내, 설문 | 안내 |

※ 교육 준비물: 담당자는 **자기 사업장 대표 작업 사진 2~3장**을 휴대폰에 담아 참석 (실습 재료)

## 4. 센터 역할 및 추진 일정

| 시기 | 센터 할 일 | 산출물 |
|---|---|---|
| ~10.17 | 지원사업장 대상 안내·모집(문자·전화), 참여 명단 콜키퍼 사업단 전달 | 참가자 명단 |
| ~10.22 | 참가자에게 준비물(작업 사진) 안내, 업종 정보 전달해 조 편성 협조 | 사전 안내문 |
| 10.25 | 센터 담당자 1명 동행: 출석 확인, 실습 조 지원 | 출석부·사진 |
| ~11.8 (2주) | 참가 사업장에 전화 확인: 개선 실행카드 1건 이행 여부, 유해요인조사 착수 여부 | 이행 확인 기록 |
| ~11월 말 | 미착수 사업장은 콜키퍼·센터 현장지원 연계 | 후속 지원 목록 |

## 5. 성과 지표

| 지표 | 목표 | 확인 방법 |
|---|---|---|
| 지원사업장 담당자 참석 | ○○개소 ○○명 | 출석부 |
| 교육 당일 개선 실행카드 작성 | 참석 사업장 100% | 실행카드 |
| 2주 내 개선 1건 이상 실행 | 참석 사업장 70% 이상 | 전화 확인·개선 전후 사진 |
| 유해요인조사 착수(또는 기존 조사 보완) | 참석 사업장 50% 이상 | 조사표 사본 확인 |

## 6. 기대 효과

- 센터 예산 없이 지원사업장의 **근골격계 유해요인조사 법적 의무 대응 역량** 확보
- 교육이 "듣고 끝"이 아니라 **2주 내 현장 개선 1건**으로 이어지는 실행 구조 마련
- 콜키퍼–센터–지원사업장 간 협력 기반을 만들어 이후 공동 현장지원으로 확장
